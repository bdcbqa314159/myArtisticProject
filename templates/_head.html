{# Shared head. Included by every template. These lines used to be duplicated byte for byte in each one — the Content-Security-Policy and the boot script among them, which are the two worst things in the file to let drift: a policy tightened on one page and not the other is a difference nobody notices until it matters. #} {# Most hosts serve no headers, so this is a meta tag. It is not an anti-XSS measure — nothing a visitor types is rendered back. What it buys: connect-src 'none' means a script that somehow got in could not send what it found anywhere. THE HASH, NOT 'unsafe-inline'. There is exactly one inline script on this site — the boot script below — and `script-src` is the directive that decides whether an injected one runs. With 'unsafe-inline' the answer was yes, for any script at all; the single script we actually wanted was indulged by a rule that indulged everything. The hash names that one script and refuses every other. The usual objection is that a hash drifts from the script it describes and silently breaks the page — so it is checked: `tools/csp-check.py` hashes the inline script in the BUILT page, after minification, and fails the build when the two disagree. If it ever did drift, the page still opens: the boot script is what adds `booting`, and `.loader` is `display: none` without it. A blocked script means no cover rather than a cover nobody can lift. `data:` is gone from img-src too. The only `data:` in either built page was this policy quoting itself — no image used one, so the permission bought nothing. #} {# Set before first paint, which is the whole point: `booting` is what shows the loader, and `.loader` is `display: none` without it. So a browser with no JavaScript never sees a cover, and cannot be stranded behind one. An inline script rather than a class in the markup, because the class in the markup has no way to take itself off again — and the failsafe below is the thing that guarantees nobody waits forever. This is why the CSP above carries 'unsafe-inline'; it is the same bargain myBureau makes, for the same reason. #}
